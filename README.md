VELMARA — a travel poster for a place that does not exist. A stdlib-only
Python program draws a sunset over a calm sea: one striped lighthouse on
a rocky islet, its beam sweeping the dusk, the sun's reflection running
down the water, and the invented place name VELMARA set large across the
sky in a hand-built stroke font. No network, no dependencies, fully
deterministic: the same run always writes the same 1024x1024 PNG.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG, under 1 MiB).
